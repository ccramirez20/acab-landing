## Español

Landing page de **ACAB (All Chuchería Are Bastards)**, un emprendimiento real de snacks
saludables, en producción desde 2026. Muestra los dos productos de la marca y permite
pedir directo por WhatsApp, sin carrito ni pasarela de pago.

### Qué hace

- Presenta los productos (Capitán Banano, Capitana Piña) con foto, descripción y precio.
- Botón de pedido que abre WhatsApp con un mensaje pre-armado (`wa.me`).
- Ficha nutricional desplegable por producto, tomada de los empaques reales.
- Identidad visual propia (estilo cartel punk/protesta, guiño al nombre de la marca).

### Stack

HTML, CSS y JavaScript **puros**, sin frameworks ni paso de build — un solo `index.html`.
Desplegado en **GitHub Pages** con dominio propio (`acabsnacks.com`) vía Cloudflare DNS.

### Ver el proyecto localmente

```bash
git clone https://github.com/ccramirez20/acab-landing.git
```

Abrir `index.html` en el navegador. No requiere instalación ni servidor.

### Contexto

Proyecto real para un negocio familiar de snacks. Cubre desde la implementación del sitio
hasta la publicación con dominio y correo propios (`contacto@acabsnacks.com`).

## English

Landing page for **ACAB (All Chuchería Are Bastards)**, a real healthy-snacks business,
live in production since 2026. It showcases the brand's two products and lets customers
order directly through WhatsApp — no cart, no payment gateway.

### What it does

- Presents the products (Capitán Banano, Capitana Piña) with photo, description and price.
- Order button that opens WhatsApp with a pre-filled message (`wa.me`).
- Expandable nutrition facts per product, taken from the real packaging.
- Custom visual identity (punk/protest-poster style, a nod to the brand's name).

### Stack

Plain **HTML, CSS and JavaScript**, no frameworks or build step — a single `index.html`.
Deployed on **GitHub Pages** with a custom domain (`acabsnacks.com`) via Cloudflare DNS.

### Run it locally

```bash
git clone https://github.com/ccramirez20/acab-landing.git
```

Open `index.html` in your browser. No install or server needed.

### Context

A real project for a family-run snacks business, end to end: from building the site to
shipping it with a custom domain and email (`contacto@acabsnacks.com`).
